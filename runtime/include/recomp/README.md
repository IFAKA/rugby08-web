# runtime/include/recomp/

`recomp_types.h`: the ABI the lifted code compiles against (register globals, memory macros, flags,
call/dispatch macros). Generated by `tools/vendor_recomp_types.py` from pcrecomp; regenerate, do not edit.
`recomp_fp.h`: the x87 stack in locals in each body that uses it (synced with `g_st` where the registers
are: calls, returns, tail jumps), else the globals.
