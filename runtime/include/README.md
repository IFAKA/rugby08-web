# runtime/include/ — the runtime's interfaces

- `rt.h` guest memory (`G2H`, `rd32`…), guest heap, `guest_call`, bridges, COM objects, logging, checks.
- `plat.h` what the host provides: window, GL, events as Win32 messages, keys, cursor, audio, input replay, arena.
- `aems.h` lifted sound-bank code · `recomp/recomp_types.h` the lifter's ABI (generated by
  `tools/vendor_recomp_types.py` from pcrecomp; exempt from the size rule, grep it).
